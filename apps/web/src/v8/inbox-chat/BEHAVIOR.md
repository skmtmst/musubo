# 受信箱の表示と操作

## 会話の頭
- 名前・経路・日時・担当者・対応状況・検索・その他・右欄の開閉を表示し、1152px と 1440px で右欄の開閉にかかわらず重ならない。名前は表示できる幅まで出し、省略時も全文を確認できる。

## 対応状況と対応マーク
- 対応状況は未対応・対応中・保留・対応済みの固定4種類で、一覧・会話の頭・右欄・絞り込み・ダッシュボードで同じ名前と色を使う。対応マークは友だちに自由に設定する別の分類で、見出しと印で対応状況と区別する。両者のデータは統合しない。
- 対応ルールの窓には、対応マークの自動変更の説明であることを示す。

## 絞り込み
- 担当者を選ぶ窓は絞り込みの窓の前に表示し、選択を即時に反映する。絞り込みの窓の位置は変えない。

## 顧客情報の展開
- 右欄の「顧客情報をすべて表示」と「表示項目を編集」は残し、重複する「情報欄をすべて見る」は出さない。友だち詳細はプロフィールの名前から開ける。

## 未読
- LINE の会話を開くと、開いた担当者の既読位置を保存する。一覧の再取得で古い応答が届いても既読を未読に戻さない。保存失敗時は未読を再表示する。新着が届いた場合はその数を表示する。
- LINE の未読数は担当者の既読位置以降の受信数とし、0は印を出さず、99以上は99+と表示する。メールの既読操作は従来どおり、Instagram の DM は開いただけで既読にしない。

## 右欄の編集
- タグを選ぶと各タグの追加・解除を保存し、再取得しても変更が残る。失敗時は変更を戻し、保存できなかった理由と再試行を知らせる。基本・対応・担当・メモも保存後に古い表示へ戻さない。
