# タグ（src/v8/tags）の動き

## 受け付ける URL と指定
- `/tags`（タグ）・`/tags?tab=fields`（友だち情報欄）・`/tags?tab=marks`（対応マーク）・`/tags?tab=searches`（保存した検索）
- 行の詳細パネル：タグは `?tag=<id>`、対応マークは `?mark=<id>`

## 対応マーク（marks-tab.tsx・絵 vKDj5）
現役の V8 タブ（src/v8/tags/marks-tab.tsx）と同じ動き。見た目だけ絵に合わせた。
- 読む：`GET /api/support-marks?accountId=`（一覧）、`GET /api/list-stats`（数の帯の人数）。アカウントを切り替えたあとに届いた古い応答は捨てる
- 数の帯：マークの数（使っている数）・未対応・対応中・過去7日の変更。集計が取れないときは「—」と理由
- 絞り込み：名前で探す・使っている／いない。表示件数 10・20・50。2ページ以上のときだけページ送り
- 並べ替え：つまみを掴んで動かす／つまみで ↑↓。共有マークは動かさない。失敗したら元に戻し、帯とお知らせに「もう一度」
- 行の右端は「…」（右クリックも同じ中身）：編集・保管する。初期値・共有マークの保管は押せない理由つき
- 保管：影響（人数・置き換え先）を読んでから確認の窓（共通のArchiveMarkDialog）
- 行を押すと右の詳細パネル。名前はその場で直せる（読んだときの版を送り、先に変わっていたら 409）
- 閲覧のみ：「マークを作る」・つまみ・編集・保管を出さない（「…」は「詳しく見る」だけ）。名前の直しは押せない

## 保存した検索（searches-tab.tsx・絵 IWnYX）
現役の V8 タブ（src/v8/tags/searches-tab.tsx）と同じ動きに、絵の下の段にある「複製して保存」を足した。
- 読む：`GET /api/saved-searches?lineAccountId=&limit=50`（一覧と数の帯）。条件の名前（タグ・マーク・シナリオ・項目）は別に読み、一覧を待たせない
- 絞り込み：条件名で探す・使っている所（あり／なし）・該当人数（1人以上／0人／未集計）。未集計は 0 人に数えない
- 行：条件名と条件の要約（「かつ」「または」）・該当・共有・使っている所（1件は名前、複数は種類ごとの数）・更新（人・日）・「友だち一覧へ」（`/friends?savedSearch=<id>`）・「…」
- 「…」（右クリックも同じ）：友だち一覧へ・編集・複製して保存（`POST /api/saved-searches`、名前に「のコピー」、50件で押せない）・上へ動かす・下へ動かす（`/api/saved-searches/reorder` へ1回で）・削除する（使用中・対象アカウント未割り当ては押せない理由つき）
- 絵につまみの列が無いので、並べ替えは「…」の上へ・下へ（今のつまみの ↑↓ と同じ動き）
- 閲覧のみ：作る口はそのまま（友だち一覧へ行くだけ）、「…」は友だち一覧へだけ。名前の直しは押せない

## 友だち情報欄（fields-tab.tsx・絵 q5gbcM）
現役の V8 タブ（src/v8/tags/fields-tab.tsx）と同じ動き。見た目だけ絵に合わせた。
- 読む：`GET /api/friend-fields?withUsage=1`（一覧）、`GET /api/friend-fields/stats`（数の帯）、`GET /api/folders?kind=friend_field`（フォルダ）。古い応答は捨てる
- 左のフォルダの列：すべて・作ったフォルダ・未分類（件数は一覧から数える）。追加・直す・並べ替え・削除（中の項目は未分類に残る）。1152 では道具の段のフォルダ選びに畳む
- 表：名前の前にフォルダの色の丸（表にフォルダ列は置かない）、差し込み名 `{{field.<key>}}`、種類（選ぶ種類は「1つ選ぶ」「いくつも選ぶ」）、入っている人、回答フォームの数、出す場所
- 並べ替え：つまみを掴んで動かす／つまみで ↑↓（共通項目は動かさない）
- 「…」（右クリックも同じ）：編集・移行（種類を変える。値が入っている項目だけ）・削除する（値が入っている項目は押せない理由つき）
- 閲覧のみ：「項目を作る」・つまみ・変える操作を出さない（「…」は「詳しく見る」だけ）

## タグを作る（create.tsx・絵 d9xoI）
- 受け付ける URL：`/tags/new`・`/tags/new?copy=<複製元のタグ>`・`/tags/new?created=<直前に作った名前>`（続けて作ったあとの知らせ）
- 読む：`GET /api/tag-groups`（フォルダ。失敗したら「読み直す」）、`GET /api/tags`（同じ名前の注意）、複製のときは `GET /api/tags/:id/definition`
- 作る前の検査：空・80文字超・制御文字は止める（今と同じ）
- 保存：`POST /api/tags/definition`（名前・フォルダ・友だち一覧に出す・手動で付けてよい）。「保存して続けて作る」は `/tags/new?created=…` へ、「タグを作る」は `/tags?highlight=<id>` へ
- 変わったところ：タグ連動（マイル・付いたときの動き）は絵のとおり作る画面に出さず、作ったあとの編集で足す。複製のときは複製元の連動をそのまま写して作る。`?linked=1`・`?reference=1` は読まない
- 入力の途中で離れるときは確認（キャンセル・左メニュー・戻る）
- 右の欄の「できあがるタグ」は共通 TagPill のふつうサイズ。名前・所属フォルダを変えると見本にも反映（2026-10-08 オーナー採用）

## 友だち情報欄を作る・編集（field-new.tsx・field-edit.tsx・field-editor.tsx・絵 w9zY5）
今の入口（src/v8/tags/field-new.tsx・src/v8/tags/field-edit.tsx）と同じ動き。中身の部品を src/v8 の FieldEditor にした。
- 受け付ける URL：`/tags/fields/new`（`?back=<戻り先>`）・`/tags/fields/edit?id=<項目>`
- 作る：`POST /api/friend-fields`（同じ作成のやり直しは同じ要求キー＝二重に作らない）。既存の項目を読めないあいだは保存しない（R514）
- 編集：`PATCH /api/friend-fields/:id`（読んだ版を送る）。409 は最新を読み直して「保存済み」か「ほかの人の変更」かを出し、入力は残す（R517）。共通項目は押せない
- 検査：項目名・差し込みの名前・選ぶ種類の選択肢・EC 側の項目名・選択肢にない既定値は止める（今と同じ）
- 種類：よく使う6つは左の選ぶカード、残りは右の札。作ったあとは変えられない（移行から）
- 選択肢の欄は絵のとおりいつも3つ見せ、「1つ選ぶ」「いくつでも選ぶ」のときだけ入力できる
- 種類「時刻」：ほかの種類と同じく押して選ぶ（時刻の保存の口ができた）。既定値は 24 時間の HH:MM（例 09:30）だけを送り、ほかの形は送る前に止める
- 絵に無い説明（タグ・情報欄・マークの違い、作ったあと変えられないもの）は板の頭の「？」へ

## 対応マークを作る・編集（mark-editor.tsx・絵 ulq9Y）
今の部品（src/v8/tags/mark-editor.tsx）と同じ動き。
- 受け付ける URL：`/tags/marks/new`・`/tags/marks/edit?id=<マーク>`
- 読む：`GET /api/support-marks`（一覧から自分を探す）。編集では `GET /api/support-marks/:id/automation-rules`（権限・未接続 404・失敗を分ける）
- 保存：作る `POST /api/support-marks`（同じやり直しは同じ要求キー）、編集 `PATCH`（読んだ版。409 は最新を出して入力を残す）。403 のあとは押させない
- 色は今の6色（保存される値は変えない）。並び順は一覧で並べ替える（ここでは今の値を保つ）
- 「新しい友だちに最初から付ける」は絵に無いので右の列の下に置いた
- きまり：編集では行（きっかけ → このマークにする）を並べ、直す・作るは今の自動変更ルールの部品を窓で開く。ゴミ箱は「止める」（`archiveAutomationRule`、確認つき）。作る画面は今と同じく「きまりを作る」を押したときだけ1つ登録する
- 保管する（左端）：初期値・共有・使用先ありは押せない（理由は title）。影響を読んでから確認の窓
- 案内の帯は絵（止めると…）と違い、今の動き（保管すると置き換わる）に合わせた文にした

## 友だち情報欄の移行＝種類を変える（field-migrate.tsx・絵 GobMd）
今の画面（src/v8/tags/field-migrate.tsx）と同じ動き（移行先の作成 R519・事前確認・実行・結果の見守り R547/R548・アカウント切替）。
- 受け付ける URL：`/tags/fields/migrate?id=<移行元>`
- 足したもの：見本の表。移行後の種類だけで `POST /api/friend-fields/:id/migration-preview`（`targetType` だけ）を読み、「今の値 → 移したあと・人数」にまとめる。移行先が無いのでサーバーは何も書き込まない（確認番号も出ない）
- 移行先の決め方は「新しい項目を作る／今ある項目へ移す」の2択（今の大きいカードを小さい選択に）
- 実行できる事前確認（確認番号つき）は「項目を作って事前確認」を押したときだけ（今と同じ）

## フォルダを追加（folder-page.tsx・絵 IjVpM）
今の画面（app/tags/folders/new/page.tsx）と同じ動き。V8 ではタグの一覧（list.tsx）の上に共通の窓を重ねる。
- 受け付ける URL：`/tags/folders/new`・`?id=<フォルダ>`（直す・削除）・`?kind=friend_field`（友だち情報欄のフォルダ。今の「作成する場所」の切り替えの代わり）
- 保存：タグのフォルダは `tag-groups` の作る・直す、友だち情報欄は `folders`（kind=friend_field）。古いクエリの応答は捨てる
- 名前と色は共通の窓で横に並ぶ。色の丸＋矢印を押すと共通部品と同じ名前つきの8色から選べる（既定は共通部品の青。WEB-C09・2026-10-09 オーナー指示）。下に色の並びや色名の注記は置かない

## タグの一覧の表（tags-tab.tsx）
- タグ名は幅によらず共通 TagPill の小さい札（白地・薄い枠・丸い角・フォルダ色の点）。押すと今までどおり編集へ進む（2026-10-08 オーナー採用）
- フォルダ列は今までどおり、1440 では出さず、1152 では出す。札の形は同じ。

## タグ一覧の星の廃止（2026-10-09・tagstar）
- 表はタグ名から始め、星の見出し・行の印・表示切り替え・取り消しを出さない。閲覧のみと1152幅も同じ。
- 「よく使う絞り込み」の「★のみ表示」を外す。以前の `?quick=starred` は絞り込みに使わず、ほかの条件だけを保つ。
- APIの `isStarred` と、作成・編集の「友だち一覧に出す」は残す。一覧からは星を更新しない。

## B-173 保管から戻す
- タグ・対応マークは通常の一覧で保管を除外し、保管の札（`?archived=1`）で保管したものだけを見る。対応マークの一覧APIに `includeArchived=1` を渡す。
- 行の「…」→「保管から戻す」→確認の窓→`POST /api/tags/:id/restore` または `POST /api/support-marks/:id/restore`。読んだ版を送る。別アカウント・古い版は拒否し、失敗は窓を残して再試行できる。
- 同じIDを戻す。保管時の友だちの付け替えは戻さない。マークの初期値・受信時の自動変更も再開しない。閲覧のみでは戻す操作を隠す。

## 長い読み込みの案内
- タグの初回の取得待ちは共通の一覧の骨格を出す。8秒続いた時だけ「時間がかかっています」と1行案内し、時間だけで失敗や自動の再取得に変えない。
- 共通ListStateの案内はアカウントの範囲で数え、通常の再描画で巻き戻さない。完了・失敗・閉じた後には残さず、アカウント切替と失敗後の再読み込みでは新しく数える。読み上げの案内は骨格の処理中の範囲と分ける。
- 既に取れた表の再取得は、今の行を保つRefreshCoverのまま。数の未取得・失敗・403・古い応答を採らない扱いは変えない。通信時間を短くする変更ではない。
- 友だち情報欄の編集・フォルダ再取得・保存中にアカウントや項目を切り替えた場合、前の結果や失敗を現在の画面に反映しない。
- 情報欄の作成中にアカウントを切り替えたら、前の重複確認・フォルダ・保存結果を使わない。現在の候補を確認できるまで保存しない。
- 切替前のアカウントで作成が成功した場合は、移動せずにそのアカウントで作成したことを知らせる。
