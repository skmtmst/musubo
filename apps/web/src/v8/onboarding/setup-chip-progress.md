# 開店準備の進み具合が変わる操作

用途：開店準備の札と「はじめの設定」が参照する情報、および再読込の対象を確認するための説明。

札の値は、共通の進捗取得と業種別の実設定から計算する。次の作成・変更・公開・停止・再開・削除・復元・接続・解除などによって、済みの数や表示状態が変わり得る。

- LINEアカウント：追加、接続確認、稼働・停止、削除、Webhookの接続状態、予約ページの設定。
- 利用機能・業種：利用機能の保存、業種の選択・変更、初期設定の適用。
- 共通の属性：タグと友だち情報欄の作成・変更・整理・削除・復元、利用するアカウントの変更。
- 友だち追加：ルールの作成・変更・公開・停止・削除・復元、条件に合わない人の受け皿とシナリオへの振り分けの変更。
- シナリオ：作成・複製・変更・開始・停止・削除、友だち追加との関連変更。
- 最初の1通：メッセージ送信の成功と配信結果の反映。
- リッチメニュー：下書きの作成・変更・公開・停止・削除。
- 飲食店：店舗の作成・選択・状態変更、卓の作成・変更・停止・削除、メニューの作成・変更・公開・停止・削除、Googleの接続と営業時間、予約受付時間・LINEの予約ページ・予約枠の作成と変更、来店フォローの有効・停止・「使わない」の保存。
- サロン・面談：メニューと担当者の作成・変更・有効化・停止・削除、担当するメニューの割り当て、Googleの接続と営業時間、LINEの予約ページの設定。
- 教室：クラスと開催日時の作成・変更・公開・停止・削除、会員の登録・変更・終了。
- EC：ストアの接続・解除、注文を受け取る設定と接続状態の変更。
- 札自体：開店準備の非表示の保存。

これらを個別の画面で列挙して監視すると、別の入口から同じ情報を変えたときに見落とす。そのため、管理画面の共通APIで更新要求が成功したときに進捗を読み直す。複数の保存が続くときはまとめ、ガイドの進行状態の保存と、確認用のプレビュー・検証は除く。画面移動やGETだけでは読み直さず、失敗した保存でも読み直さない。対象アカウントが分かる場合は、そのアカウントの札だけを更新する。

別端末・外部サービス・予約枠の時刻経過など、開いている画面で更新要求を行わずに変わる情報は、その操作の成功をブラウザが受け取れない。タブへ戻ったときの再読込と、最初の1通を待つ間の定期確認で反映する。
