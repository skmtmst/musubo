# 電話の画面の今日

- `/m/today` は予約を見る権限がある人に、一般予約は既存の今日の予約 API、飲食店は選択アカウントに属する店舗の予約 API を使って時刻順に表示する。金額と操作は出さない。
- 取得中・取得失敗（再試行）・予約なしを区別する。店を替えたり画面を離れたりした後の古い応答は使わず、日本時間の日付が変わったら読み直す。
- 店が未選択または予約を見る権限がない場合は、共通の外枠が案内する。
- 一覧 API の上限200件に達したときは全件数と誤解させず、先頭200件と PC の予約台帳への入口を出す。
- 予約機能が利用できないアカウントは取得を行わず、利用できないことを案内する。
- 飲食店は取消・却下・期限切れを件数に含めず、対象店舗がないときはその旨を表示する。
- `/m` の初期表示は飲食店なら今日、その他はトークを優先し、権限で見えない場合は最初に利用できるタブへ進む。
