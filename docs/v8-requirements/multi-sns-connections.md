# Googleビジネス・Instagram 複数連携の要件

- 作成: 2026-11-16。ワークスペース「GoogleビジネスとInstargram複数連携」の要件整理。§5 の各点は 2026-11-16 に利用者（Masato）が本ワークスペースのチャットで決定済み（Q6 は同日の追加決定 Q6' で訂正）。
- 背景: `docs/musubo-pricing-onboarding-integration.md` の「複数アカウント接続と複数投稿先選択は別チャットの開発範囲」が本件。課金側（追加連携枠）は設計済み・操作画面は未接続。
- UI変更は段ごとに本依頼専用の新規 Pen を作り、ファイル・版・フレームの明示承認を得てから実装する。承認前に実装・PR統合・配備へ進まない。

## 1. 目的（利用者が最終的にできること）

1つのLINEアカウント（店舗）に、Googleビジネスのロケーションを複数・Instagramアカウントを複数接続できる。投稿を作るときに、どの接続へ出すかを選び、複数のGoogleロケーションと複数のInstagramへ同時に投稿できる。

## 2. 現状（2026-11-16 調査済み）

- 設定→SNS連携・DB・API・投稿フローのすべてが「1 LINEアカウント = Google 1接続（1ロケーション）+ Instagram 1接続」の単一前提。
  - DB: `rt_google_connections.store_id UNIQUE`（migration 446）、`instagram_connections.line_account_id PRIMARY KEY`（migration 754）。
  - Googleのロケーション変更は「切り替え」扱いで、取り込み済みの口コミ・投稿・プロフィール・数値を全削除する破壊的操作。
  - 投稿の宛先指定は不可（Googleは接続済みロケーション固定、Instagramは ON/OFF のみで `LIMIT 1` の単一接続へ送る）。
  - Googleビジネス画面は「画面内に店舗選択を出さない。右上のLINEアカウント選択で切り替える」（反映履歴 2076、テストで固定）。
- 唯一の複数対応は「同じ統括内の複数LINEアカウントで同じInstagramを共有」（migration 754）。逆方向（1 LINEに複数IG）は不可。

## 3. 流用する既存設計（前提。本件で変えない）

- **課金（追加連携枠）**: `packages/shared/src/musubo-pricing.ts` / `musubo-linked-addition.ts` が複数連携前提で設計済み。
  - LINEアカウントごとに Google・Instagram 各1件目は基本料金に含む。追加枠数 = max(Google数, Instagram数) − 1、1枠 月額¥3,300（税込・初期値）。
  - 各サービス 10件まで。11件以上は個別見積もり（`musuboLinkedAdditionPrice` が拒否）。
  - 無料期間中の追加は ¥0、支払い中は月次期間の日割り。料金確認画面の部品 `apps/web/src/v8/hq/linked-account-addition.tsx` / `linked-account-removal.tsx` は実装済み・未接続。
- **Instagramのテナント境界**: 同一統括内の共有可・別統括への接続拒否（APIとDBトリガの二重防御）は維持。
- **Google方針**: スコープは `business.manage` のみ、Google由来データは取得から28日で削除、送信系は `confirmed: true` を要求（利用者の操作からのみ実行）。
- **UI承認手順**: 本依頼専用の新規 Pen を作り、ファイル・版・フレームの明示承認後に実装。

## 4. 確定した仕様（§5 の決定を反映）

### 4-1. 設定 → SNS連携（接続の管理）
- Googleカード・Instagramカードを「接続の一覧 + 追加 + 個別解除」に変える。各行に接続先（ロケーション名 / @ユーザー名）と状態の札。
- **契約枠（2026-11-16 決定 Q5。Q6 は 2026-11-16 の追加決定で訂正。§5 参照）**: 契約時にヒアリングした連携個数を「契約枠」として、LINEアカウントごとに**1つの数**（両サービス共通）で保持する。値は 1 + 合意済みの追加枠数で、既定は1（基本料金に Google・Instagram 各1個ぶんが入るため）。サービス別に別の数は持たない。契約枠の設定・変更はHQ側で行う。
  - 契約枠の範囲内の追加は、料金確認を挟まずそのまま認可画面へ進む（契約時に個数と料金を合意済みのため）。
  - 契約枠を超える追加は、同じ画面内で料金確認（追加枠 1枠 月額¥3,300税込・無料期間中は¥0、追加時は日割り）を出し、同意後すぐ認可画面へ進む（サポート連絡は不要）。
  - 各サービス10個の上限を超える追加（11個目〜）は個別見積もりの案内で止める。
  - 各カードの件数表示は「連携 n個（契約枠 m個）」。
- 有料の追加枠数の数え方は §3 の既存設計をそのまま正本とする: **有料枠 = max(0, max(Google数, Instagram数) − 1)**。追加枠1枠（¥3,300税込）で Google・Instagram が**各1個ずつ同時に増える**（2枠なら各3個）。`packages/shared` の `linkedAccountSlots` / `musuboLinkedAdditionPrice` は変更しない（単価・上限10・無料期間¥0・日割りも流用）。
  - 契約枠は請求式に入れない。請求は接続数から導出し、契約枠は「料金確認を挟むかどうか」と「連携 n個（契約枠 m個）」の表示にだけ使う（解除時に次回請求から減額する既存の見せ方を保つため）。
  - この数え方の帰結: 少ないほうのサービスへの追加は有料枠が増えない（例 契約枠1・Google3・Instagram1 で IG を足しても枠は2のまま・追加請求なし）。多いほうの個数が変わらない解除は減額しない（例 G3/I3 で IG を1件解除しても枠は2のまま）。
- 解除は接続ごとの個別解除に変え、解除時に枠数の減少と料金を確認（`linked-account-removal`）。現行の「店舗の切り替え（全削除）」は、複数保持ができるため廃止し「追加」と「個別解除」で表す。
- 1件目の接続の文言「接続する店舗は、1つのLINEアカウントにつき1店舗です」は撤去し、枠の説明に差し替え。
- Googleは同一Googleアカウントの複数ロケーションも、別Googleアカウントのロケーションも接続できる（課金は接続ロケーション数で数える）。
- Instagramは別のMetaログインで別アカウントを追加接続できる。同一統括内の共有ルールは接続ごとに適用。

### 4-2. 投稿（宛先の選択と複数同時投稿）
- 投稿作成画面に「投稿先」の区画を新設。接続済みのGoogleロケーション（複数選択）と、「Instagramにも投稿する」の宛先（接続済みIGから複数選択）を選べる。
- 公開前の最終確認に宛先の一覧を出す（現行の「操作先のLINEアカウントと店舗を示す」方針を宛先一覧に拡張）。
- 投稿結果は宛先ごとに記録・表示（済み / 失敗・再試行 / なし の札を宛先単位に）。失敗した宛先だけ再送できる。
- DB は投稿と宛先を分け、`rt_google_posts` の単数の Instagram 列は宛先子テーブルへ移す（additive-only 規約に従い table-rebuild 形式。migration は番号ごとにオーナー承認）。

### 4-3. 取り込みデータ（口コミ・プロフィール・数値）
- 接続（ロケーション）ごとに取り込み・保存し、28日削除も接続単位で適用。
- Googleビジネス画面に接続の切り替え（セレクタ）を新設し、口コミ・プロフィール・数値・投稿一覧は選択中の接続のものを表示（§5-Q2 決定）。
- 営業時間の正本（予約枠・営業中判定・SLA等が参照）は「主連携」1件を定め、その接続のプロフィールを正本とする（§5-Q2 決定）。主連携の既定は1件目の接続で、設定画面から変更できる。
- **主連携は Googleビジネスの接続にのみ設ける（2026-11-16 決定）**。Instagram は DM を全接続分受信し、投稿宛先も投稿時に選ぶため、「正本を1件に定める」機能が存在しない。Instagram カードには主連携のバッジ・切替ボタンを置かない。設定画面の Google カードには主連携の説明文（営業時間・店舗情報の正本である旨）を表示する。

### 4-4. Instagram 受信（DM）
- 接続済みの全IGアカウントのDMを受信する（§5-Q4 決定）。受信箱の各スレッドに、どのIGアカウント宛かのアカウント名（@ユーザー名）を表示する。返信は受信したIGアカウントから送る。

## 7. 受け入れ条件（段ごとに着手時 nen-harness task へ登録）

第1段（複数接続・設定画面・課金接続）:
1. 1つのLINEアカウントにGoogleロケーション2件・Instagram 2件を接続でき、設定画面に一覧表示される。
2. 契約枠（両サービス共通の1つの数・既定1）の範囲内の追加は、料金確認なしでそのまま認可へ進む。各カードに「連携 n個（契約枠 m個）」が表示される。
3. 契約枠を超える追加は、画面内の料金確認（有料枠 = max(0, max(Google数, Instagram数) − 1)、1枠 ¥3,300税込で両サービスが各1個増える・無料期間中は¥0・追加時は日割り）で同意した場合にのみ認可へ進む。各サービス11個目は個別見積もり案内で止まる。
4. 接続の個別解除で他の接続のデータが消えない。解除時に枠数の減少が確認できる（契約枠は変わらない）。
5. 別統括のInstagram接続は従来どおり拒否される。既存の単一接続環境は移行後も無変更で動く。

第2段（投稿宛先）:
6. 投稿作成で宛先を複数選択でき（初期は全選択）、公開前の最終確認に宛先一覧が出る。公開後に宛先ごとの結果が表示され、失敗宛先のみ再送できる。

第3段（受信・既存画面）:
7. 複数IGのDMがすべて受信箱に届き、スレッドにIGアカウント名が表示され、返信が受信したIGから送られる。
8. Googleビジネス画面の接続セレクタで口コミ・プロフィール・数値を接続ごとに表示でき、営業時間の正本は主連携の接続に従う。
