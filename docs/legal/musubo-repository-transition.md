# musubo 専用リポジトリの移行

`skmtmst/musubo` は公開リポジトリとして作成した。2026-11-06 時点で `skmtmst/line-harness-oss` の `codex/development`（`acfe29abe56664773c732e8cd31369f9b9f0a646`）と `main`（`e50f106c1e9bb862a244d6cb08a414022add340c`）を履歴付きでコピーした。その後、当時の検証公開版 `20bfff7251a5543c7da103c188ea18c8db89aff2` を通常の PR で取り込み、2026-11-07 に共有検証環境の配備経路を新リポジトリへ切り替えた。元リポジトリで進行中の PR は別担当が整理し、完了後の成果を差分確認・通常の PR と検査で取り込む。

## 新しい開発依頼の入口

2026-11-06 以降、新規の musubo 開発はこのリポジトリの最新 `codex/development` を基準にする。既存の旧リポジトリ向け PR は旧リポジトリで処理し、必要な成果を新リポジトリへ取り込む際は、履歴と差分を照合して別の PR で検査する。共有検証配備は新リポジトリの公式 workflow を使う。本番配備と D1 更新は別の経路・承認が必要で、検証配備の完了をもって許可されたものとは扱わない。

## 著作権とライセンス

オーナーの希望する今後の自社制作部分の著作権者表記は **Shed Products株式会社**。ただし、表示を変更するだけで元コードや他の開発者の著作権が会社へ移るとは扱わない。制作契約・職務著作・譲渡の範囲を確認し、会社が権利を持つ部分を特定する。

元コードに付く Shudesu の著作権表示と MIT 許諾文は維持する。MIT で既に公開された版の許諾も取り消したものとは扱わない。ルートの `LICENSE`、各 package の `license` と公開設定、README、配布物の表示は、権利範囲と配布方針の確認後にまとめて変更する。今回のリポジトリ移行ではライセンスの効力を変更しない。

確認先：[MIT License](https://opensource.org/license/mit)、[既存の配布表示の確認事項](distribution-and-terms.md)。
