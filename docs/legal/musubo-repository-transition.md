# musubo 専用リポジトリの移行

`skmtmst/musubo` は公開リポジトリとして作成した。2026-11-06 時点で `skmtmst/line-harness-oss` の `codex/development`（`acfe29abe56664773c732e8cd31369f9b9f0a646`）と `main`（`e50f106c1e9bb862a244d6cb08a414022add340c`）を履歴付きでコピーした。以後の更新は別に同期・統合する必要がある。元リポジトリの進行中の PR、Issue、秘密情報、配備先は移していない。実行環境の運用は切り替えていない。

## 新しい開発依頼の入口

2026-11-06 以降、新規の musubo 開発はこのリポジトリの最新 `codex/development` を基準にする。既存の旧リポジトリ向け PR は旧リポジトリで処理し、必要な成果を新リポジトリへ取り込む際は、履歴と差分を照合して別の PR で検査する。新リポジトリには開発用の CI がある一方、共有検証・本番への配備経路はまだない。新しい開発成果の配備依頼は、配備経路の移管を完了するまで未完了として扱う。

## Actions と配備

共有検証配備の切り替え条件と現在の停止理由は[切り替え準備](../deploy/musubo-staging-cutover.md)に記録する。

開発中に PR 検査を使えるよう、Actions 全体は有効にする。配備、DB 更新、上流取り込み、外部通知の旧リポジトリ向け経路は、新リポジトリから実行できないように保つ。新リポジトリには Cloudflare の秘密情報・環境変数・配備 Environment を登録しない。新リポジトリへの配備経路を開くときは、対象環境、ロック、最新統合版、復旧方法を別に検証してから決める。

## 著作権とライセンス

オーナーの希望する今後の自社制作部分の著作権者表記は **Shed Products株式会社**。ただし、表示を変更するだけで元コードや他の開発者の著作権が会社へ移るとは扱わない。制作契約・職務著作・譲渡の範囲を確認し、会社が権利を持つ部分を特定する。

元コードに付く Shudesu の著作権表示と MIT 許諾文は維持する。MIT で既に公開された版の許諾も取り消したものとは扱わない。ルートの `LICENSE`、各 package の `license` と公開設定、README、配布物の表示は、権利範囲と配布方針の確認後にまとめて変更する。今回のリポジトリ移行ではライセンスの効力を変更しない。

確認先：[MIT License](https://opensource.org/license/mit)、[既存の配布表示の確認事項](distribution-and-terms.md)。
